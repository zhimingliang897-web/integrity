## 一、整体复习策略

### 课程模块划分
根据课程大纲和期中考试范围（Lecture 1-5），本课程前半部分可划分为以下核心模块：

1.  **时间序列特性与平稳性** - 基础概念与前提
2.  **平稳时间序列模型** - 核心模型体系
3.  **参数估计** - 模型拟合方法
4.  **模型识别与诊断** - 建模流程关键步骤
5.  **预测** - 模型应用与目标

### 模块作用与难度
- **模块1**：奠定理论基础，概念多但计算相对简单。**难度：中等**
- **模块2**：课程核心，涉及大量公式推导和性质计算，是考试计算题的重灾区。**难度：高**
- **模块3**：方法论，理解三种估计方法的原理和适用场景即可，计算量适中。**难度：中等**
- **模块4**：连接理论与应用的桥梁，涉及假设检验和决策，需要综合运用前序知识。**难度：高**
- **模块5**：应用目标，计算步骤明确，但需熟练掌握模型性质。**难度：中等**

**核心复习思路**：以**模块2（ARMA模型）** 为中心，向前理解**平稳性**，向后掌握**估计、识别、预测**。所有计算和推导都围绕ARMA模型的性质展开。

## 二、分章节复习路径

### Lecture 1: 时间序列特性
**等级：【必学】**

**核心概念**：
- 时间序列分解（加法/乘法模型）
- 平稳性（严格平稳 vs 弱平稳）
- 自协方差函数 (ACVF, γ_k) 与自相关函数 (ACF, ρ_k)
- 样本均值、样本ACVF、样本ACF

**关键公式/方法**：
- 弱平稳定义：均值恒定，ACVF只与滞后阶数k有关。
- ACVF与ACF的关系：ρ_k = γ_k / γ_0。
- 样本ACVF计算公式：c_k = (1/(N-1)) Σ (X_t - X̄)(X_{t-k} - X̄)。
- **重要性质**：γ_k = γ_{-k}，ρ_k = ρ_{-k}。

**典型应用**：
- 判断一个过程是否平稳（如Assignment 1 Q2）。
- 计算给定过程的均值函数和ACVF（如Assignment 1 Q2）。
- 理解序列相关性对样本均值方差的影响（有效样本量n_eff）。

### Lecture 2: 平稳时间序列模型
**等级：【必学】【核心】**

**核心概念**：
- 移动平均模型 MA(q)
- 自回归模型 AR(p)
- 自回归移动平均模型 ARMA(p,q)
- 因果性与可逆性
- AR特征多项式与MA特征多项式

**关键公式/方法**：
1.  **MA(q)模型**：
   - X_t = Z_t + θ_1 Z_{t-1} + ... + θ_q Z_{t-q}
   - **ACF性质**：在滞后q处截尾，即ρ_k = 0 for k > q。
   - **可逆性条件**：MA特征多项式θ(z)的所有根在单位圆外。

2.  **AR(p)模型**：
   - X_t = φ_1 X_{t-1} + ... + φ_p X_{t-p} + Z_t
   - **ACF性质**：拖尾（指数衰减或振荡衰减）。
   - **因果性条件**：AR特征多项式φ(z)的所有根在单位圆外。
   - **Yule-Walker方程**：γ_k = φ_1 γ_{k-1} + ... + φ_p γ_{k-p}，用于求解ACVF。

3.  **ARMA(p,q)模型**：
   - 结合AR和MA特性。
   - **ACF性质**：在滞后q后，表现为AR(p)的拖尾形式。
   - **计算ACVF的两种方法**：
     - **方法一（逐步法）**：对k=0,1,...,q，用模型乘以X_{t-k}并取期望，建立方程组求解γ_0,...,γ_q。对k>q，使用Yule-Walker递推。
     - **方法二（因果表示法）**：将模型写成因果表示X_t = Σ ψ_j Z_{t-j}，则γ_k = σ_Z^2 Σ ψ_j ψ_{j+k}。

**典型应用**：
- 判断模型的平稳性、因果性、可逆性（如Assignment 1 Q3）。
- 计算MA、AR、ARMA模型的ACVF和ACF（如Assignment 1 Q3, Q4, Q5；Assignment 2 Q2）。
- 将AR模型写成MA(∞)形式（因果表示），并求ψ_j系数（如Assignment 1 Q5）。

### Lecture 3: 参数估计
**等级：【重要】**

**核心概念**：
- 矩估计法
- 条件最小二乘法
- 极大似然估计法

**关键公式/方法**：
- **矩估计**：用样本矩（样本均值、样本ACF）等于理论矩，建立方程求解参数。
- **最小二乘估计**：最小化残差平方和。对于AR模型，可转化为线性回归问题。
- **极大似然估计**：在正态性假设下，最大化似然函数。

**典型应用**：
- 对简单模型（如MA(1)）进行矩估计或最小二乘估计（如Assignment 2 Q1）。
- 理解不同估计方法的优缺点。

### Lecture 4: 模型识别与诊断
**等级：【必学】**

**核心概念**：
- 偏自相关函数 (PACF, φ_kk)
- 模型识别的Box-Jenkins方法
- 信息准则
- 残差分析

**关键公式/方法**：
- **PACF定义**：φ_kk是X_t和X_{t-k}在去除了X_{t-1},...,X_{t-k+1}线性影响后的相关系数。
- **PACF与模型识别**：
  - AR(p)模型的PACF在滞后p处截尾。
  - MA(q)模型的PACF拖尾。
- **模型识别流程**：
  1. 根据样本ACF和PACF的形态初步判断模型类型和阶数。
  2. 使用AIC/BIC进行模型阶数选择。
  3. 对选定模型进行参数估计。
  4. 进行残差分析（如Ljung-Box检验），检验残差是否为白噪声。
- **假设检验**：
  - 检验ρ_k是否为0：Z统计量 = r_k / sqrt((1+2Σr_j^2)/n)。
  - 检验φ_kk是否为0：Z统计量 = sqrt(n) φ̂_kk。

**典型应用**：
- 根据给定的样本ACF和PACF序列，识别合适的ARMA模型（如Assignment 2 Q3, Q4）。
- 进行模型阶数选择的假设检验。

### Lecture 5: 预测
**等级：【必学】**

**核心概念**：
- 事前预测 vs 事后预测
- 最小均方误差预测 (MMSEP)
- 指数平滑法（简单、Holt、Holt-Winters）

**关键公式/方法**：
- **ARMA模型预测**：
  - **基本原理**：基于信息集{X_1,...,X_n}，预测X_{n+h}的最佳预测是其条件期望。
  - **递推预测**：利用ARMA模型的递归结构，逐步向前预测。
  - **预测误差**：e_n(h) = X_{n+h} - X̂_{n+h|n}。其方差可由模型的MA(∞)表示系数计算。
  - **预测区间**：在正态性假设下，X̂_{n+h|n} ± z_{α/2} * sqrt(Var(e_n(h)))。
- **指数平滑法**：
  - 简单指数平滑（SES）：适用于无趋势、无季节性的序列。ℓ_t = αX_t + (1-α)ℓ_{t-1}。
  - Holt方法：适用于有线性趋势的序列。更新水平和趋势。
  - Holt-Winters方法：适用于有趋势和季节性的序列。

**典型应用**：
- 对AR、MA、ARMA模型进行多步预测（如Assignment 2 Q5）。
- 计算预测误差的方差和预测区间。
- 更新预测（当获得新观测值时）。

## 三、时间规划建议（假设考前3周）

### 第1周：夯实基础与核心模型
- **目标**：彻底掌握Lecture 1和Lecture 2。
- **每日安排**：
  - **Day 1-2**：复习Lecture 1。重点理解平稳性定义，熟练计算ACVF/ACF。完成Assignment 1中相关题目。
  - **Day 3-5**：攻克Lecture 2。这是重中之重。分三天分别深入理解MA、AR、ARMA模型。**务必亲手推导**每个模型的ACVF/ACF计算过程（参考Assignment 1和2的解答）。理解因果性、可逆性条件。
  - **Day 6-7**：整合练习。做综合题，如给定一个ARMA(1,1)模型，要求判断平稳性、计算γ_0, γ_1, γ_2，并写出因果表示。

### 第2周：掌握方法与流程
- **目标**：掌握参数估计、模型识别和预测方法。
- **每日安排**：
  - **Day 1-2**：学习Lecture 3。理解三种估计方法的思想。练习矩估计和最小二乘估计的计算（Assignment 2 Q1）。
  - **Day 3-4**：学习Lecture 4。掌握PACF的概念和模型识别流程。练习根据样本ACF/PACF识别模型（Assignment 2 Q3, Q4）。
  - **Day 5-7**：学习Lecture 5。重点掌握ARMA模型的预测方法。练习多步预测、预测误差方差计算和预测区间（Assignment 2 Q5）。

### 第3周：综合演练与查漏补缺
- **目标**：模拟考试，强化薄弱环节。
- **每日安排**：
  - **Day 1-3**：**模拟考试**。使用《Midterm Review》中的Exercises和往年作业题，在限时（如2小时）内独立完成。模拟考试环境。
  - **Day 4-5**：**错题分析与专题突破**。针对模拟考试中暴露的薄弱环节（如ARMA的ACVF计算、预测更新等），进行专项练习和公式推导。
  - **Day 6**：**整理公式表**。根据复习内容，整理一份自己的A4公式表。这个过程本身就是极好的复习。
  - **Day 7**：**最后回顾**。快速浏览所有讲义的关键页，重温核心定理和易错点。保持良好心态。
