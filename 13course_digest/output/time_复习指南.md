### 📌 模块2：时间序列特征与平稳性

**等级：【必学】**

**来源**：
- `1. Characteristics of Time Series.pdf` 第2-3页
- `Midterm Review.pdf` 第2-3页

**核心概念**：

| 概念 | 定义/公式 |
|------|----------|
| **严平稳** | 联合分布不随时间平移改变 |
| **弱平稳** | 均值恒定 + 自协方差仅依赖滞后 |
| **均值函数** | $\mu_t = E[X_t]$ |
| **自协方差函数 (ACVF)** | $\gamma_k = Cov(X_t, X_{t-k})$ |
| **自相关函数 (ACF)** | $\rho_k = \frac{\gamma_k}{\gamma_0}$ |

**关键性质**：
- $\rho_0 = 1$, $|\rho_k| \leq 1$
- 对称性：$\gamma_k = \gamma_{-k}$, $\rho_k = \rho_{-k}$
- 非负定性

**典型应用**（来自 Assignment 1 Q2）：
- 判断序列是否平稳
- 计算均值函数和自协方差函数

---

### 📌 模块3：ARMA模型族

**等级：【必学】**

**来源**：`2. Models for Stationary Time Series.pdf` 第2-3页

#### 3.1 MA(q) 模型

**定义**：
$$X_t = Z_t + \theta_1 Z_{t-1} + \cdots + \theta_q Z_{t-q} = \theta(B)Z_t$$

**核心公式**：
| 量 | 公式 |
|----|------|
| 均值 | $E[X_t] = 0$ |
| 方差 | $\gamma_0 = \sigma^2 \sum_{j=0}^{q}\theta_j^2$ |
| ACF | $\rho_k = \frac{\sum_{j=0}^{q-k}\theta_j\theta_{j+k}}{\sum_{j=0}^{q}\theta_j^2}$, $k \leq q$；$\rho_k = 0$, $k > q$ |

**关键特征**：**ACF在滞后q后截尾**

#### 3.2 AR(p) 模型

**定义**：
$$X_t = \phi_1 X_{t-1} + \cdots + \phi_p X_{t-p} + Z_t$$

**平稳性条件**：特征方程 $\phi(z) = 1 - \phi_1 z - \cdots - \phi_p z^p = 0$ 的根在单位圆**外**

**关键特征**：**ACF拖尾，PACF在滞后p后截尾**

#### 3.3 ARMA(p,q) 模型

**定义**：
$$X_t - \phi_1 X_{t-1} - \cdots - \phi_p X_{t-p} = Z_t + \theta_1 Z_{t-1} + \cdots + \theta_q Z_{t-q}$$

**平稳性**：AR部分特征根在单位圆外
**可逆性**：MA部分特征根在单位圆外

**典型应用**（来自 Assignment 1 Q3-Q5）：
- 判断AR过程平稳性
- 计算自协方差 $\gamma_1, \gamma_2$
- 特征方程根与$\psi$权重的关系

### 📌 模块4：参数估计

**等级：【重要】**

**来源**：`3. Parameter Estimation.pdf` 第2-3页

**三种方法**：

| 方法 | 思想 | 适用性 |
|------|------|--------|
| **矩估计** | 样本矩 = 总体矩 | 简单，但效率低 |
| **最小二乘** | 最小化残差平方和 | AR模型直接，MA需迭代 |
| **极大似然 (MLE)** | 最大化似然函数 | 最优，需分布假设 |

**样本统计量**：
$$\bar{X} = \frac{1}{N}\sum_{t=1}^{N}X_t, \quad c_k = \frac{1}{N-1}\sum_{t=k+1}^{N}(X_t - \bar{X})(X_{t-k} - \bar{X})$$

**典型应用**（来自 Assignment 2 Q1）：
- MA(1)的最小二乘估计

---

### 📌 模块5：模型识别与诊断

**等级：【必学】**

**来源**：`4. Model Identification and Diagnostics.pdf` 第2-3页

#### 5.1 偏自相关函数 (PACF)

**定义**：$\phi_{kk}$ 是 $X_t$ 与 $X_{t-k}$ 在去除 $X_{t-1}, \ldots, X_{t-k+1}$ 影响后的相关系数

**回归解释**：
$$X_t = \alpha_{k,1}X_{t-1} + \cdots + \alpha_{k,k}X_{t-k} + e_{t,k}$$
则 $\phi_{kk} = \hat{\alpha}_{k,k}$

#### 5.2 模型识别规则

| 模型 | ACF模式 | PACF模式 |
|------|---------|----------|
| **AR(p)** | 拖尾 | **p后截尾** |
| **MA(q)** | **q后截尾** | 拖尾 |
| **ARMA(p,q)** | 拖尾 | 拖尾 |

**典型应用**（来自 Assignment 2 Q3-Q4）：
- 根据样本ACF模式识别MA模型
- 根据样本PACF模式识别AR模型

#### 5.3 阶数选择准则

- **AIC** = $-2\ln L + 2k$
- **BIC** = $-2\ln L + k\ln n$

选择使AIC/BIC最小的模型。

### 📌 模块6：预测

**等级：【必学】**

**来源**：`5. Forecasting.pdf` 第2-3页

#### 6.1 简单预测方法

| 方法 | 适用场景 | 公式 |
|------|----------|------|
| **简单指数平滑** | 无趋势无季节 | $\hat{X}_{t+1|t} = \alpha X_t + (1-\alpha)\hat{X}_{t|t-1}$ |
| **Holt's** | 有趋势 | 水平+趋势分量 |
| **Holt-Winters'** | 有趋势+季节 | 水平+趋势+季节分量 |

#### 6.2 最小均方误差预测 (MMSE)

**核心思想**：$\hat{X}_{t+h|t} = E[X_{t+h} | X_1, \ldots, X_t]$

#### 6.3 AR模型预测

对于AR(p)：$\hat{X}_{t+h|t}$ 可递推计算

#### 6.4 MA模型预测

- 对于MA(q)，超过q步预测 = 均值
- 需要估计历史噪声 $Z_t$

#### 6.5 预测区间

**95%预测区间**：$\hat{X}_{t+h|t} \pm 1.96 \sqrt{Var(e_t(h))}$

**典型应用**（来自 Assignment 2 Q5）：
- 计算预测值 $\hat{X}_{204|203}$, $\hat{X}_{206|203}$
- 计算预测区间
- 预测更新

## 五、考试重点公式速查表

### 平稳性判断
- AR(p)平稳：特征根在单位圆**外**
- MA(q)平稳：总是平稳
- MA(q)可逆：MA特征根在单位圆**外**

### ACF/PACF识别
```
AR(p):  ACF拖尾, PACF截尾(p后)
MA(q):  ACF截尾(q后), PACF拖尾
ARMA:   两者都拖尾
```

### 预测误差方差
$$Var(e_t(h)) = \sigma^2 \sum_{j=0}^{h-1}\psi_j^2$$

### Yule-Walker方程（AR(p)）
$$\gamma_k = \phi_1\gamma_{k-1} + \cdots + \phi_p\gamma_{k-p}, \quad k \geq 1$$

## 六、常见易错点提醒

1. **平稳性判断**：AR特征方程是 $1 - \phi_1 z - \cdots = 0$，根在单位圆**外**才平稳
2. **ACF截尾**：MA(q)的ACF在 $k > q$ 时为**零**，不是"很小"
3. **预测更新**：新观测值到达后，需要重新计算预测
4. **预测区间**：预测步数越大，区间越宽（不确定性增加）
