### 错题分析方法

1. **计算错误** → 检查公式记忆、计算器操作
2. **概念错误** → 回到Lecture Notes对应章节
3. **方法错误** → 总结题型模板，如：
   - **AR模型γ_k计算模板**：先求特征根→判断平稳性→建立Yule-Walker方程→求解
   - **预测区间模板**：先求预测值→计算预测误差方差→代入±1.96√Var

### 自行构造练习题建议

- **修改参数**：将作业题中的系数改为其他值（如ϕ₁=0.6, ϕ₂=-0.3）
- **修改阶数**：将AR(2)改为AR(1)或AR(3)
- **修改数据**：更换预测题中的观测值

## 五、A4公式纸建议内容

```
【AR模型】
- 特征方程：1-ϕ₁x-ϕ₂x²-...-ϕ_px^p=0
- 平稳条件：所有根|xi|>1
- Yule-Walker：γ_k = ϕ₁γ_{k-1}+...+ϕ_pγ_{k-p}, k≥1

【MA模型】
- 可逆条件：特征根|xi|>1
- γ_k公式（MA(q)）：k>q时γ_k=0

【ACF与PACF特征】
- AR(p)：ACF拖尾，PACF p阶截尾
- MA(q)：ACF q阶截尾，PACF拖尾

【预测】
- 一步预测误差方差：σ²_Z
- 95%预测区间：X̂ ± 1.96√Var(e)

【Z检验】
- Z = √n × r_k 或 Z = √n × ϕ̂_kk
- 临界值：|Z|>1.96 → 拒绝H₀
```
