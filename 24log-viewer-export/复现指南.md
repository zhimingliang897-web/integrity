# Claude 日志查看器 — 复现指南

在另一台电脑上复现本辅助脚本时，按以下步骤操作即可。

---

## 1. 环境要求

- **Node.js**（任意较新版本）用于运行 `node server.js`  
  **或**  
- **Python 3** 用于运行 `python server.py`

无需 npm / pip 依赖（无 package.json / requirements.txt），解压即用。

---

## 2. 部署步骤

1. 将本压缩包解压到任意目录（例如桌面或 `%USERPROFILE%`）。
2. 将解压后的 **`log-viewer`** 文件夹整体放到：
   - **Windows**：`%USERPROFILE%\.claude\log-viewer`
   - **macOS/Linux**：`~/.claude/log-viewer`
   
   若希望使用其他路径，可通过环境变量 `CLAUDE_PROJECTS_DIR` 等自定义数据源，详见解压后的 `log-viewer/README.md`。
3. 在终端中进入 log-viewer 目录，**二选一**启动：
   ```powershell
   cd %USERPROFILE%\.claude\log-viewer
   node server.js
   ```
   或：
   ```powershell
   python server.py
   ```
4. 浏览器打开终端中打印的地址（默认 `http://127.0.0.1:3847`）。端口被占用时服务会自动尝试后续端口并提示实际端口。

---

## 3. 数据源说明

- **主数据源**：`%USERPROFILE%\.claude\projects`（或 `~/.claude/projects`）。  
  即 Claude / Cursor 的对话 transcript，各项目下的 `.jsonl` 文件。log-viewer 会扫描该目录并展示项目、会话与时间线。
- 若需「按会话 ID 查看 tool-logs 原始 .txt」：需配置 **hooks**（见下），且必须使用 **Node 版** `server.js`（Python 版不提供 `/api/sessions`、`/api/sessions/:id/log`）。

---

## 4. 可选：hooks 配置（tool-logs）

若希望将每次工具调用的完整 JSON 写入 `~/.claude/tool-logs\*.txt`，并在 log-viewer 中通过 Node 版接口查看：

1. 将本压缩包内的 **`hooks/log-tool-detail.js`** 复制到：
   - **Windows**：`%USERPROFILE%\.claude\hooks\log-tool-detail.js`
   - **macOS/Linux**：`~/.claude/hooks/log-tool-detail.js`
2. 在 Claude Code / Cursor 中配置使用该 hook（具体方式请参考当前使用的 Claude CLI 或 Cursor 的 hook 文档）。  
   配置成功后，运行 claude 时的工具调用会追加到 `%USERPROFILE%\.claude\tool-logs\` 下按会话 ID 命名的 `.txt` 文件中。

---

## 5. 配置项（环境变量）

| 项 | 默认值 | 环境变量 |
|----|--------|----------|
| 监听端口 | 3847 | `CLAUDE_LOG_VIEWER_PORT` |
| 项目/会话数据目录 | `%USERPROFILE%\.claude\projects` | `CLAUDE_PROJECTS_DIR` |
| tool-logs 目录（仅 Node 版） | `%USERPROFILE%\.claude\tool-logs` | `CLAUDE_TOOL_LOG_DIR` |

---

## 6. 解说 API 配置（生成解说 / 提问）

用于页面中的「生成解说」和「提问」功能：

1. 在 **log-viewer** 目录下，将 `explain-config.example.json` 复制为 `explain-config.json`。
2. 编辑 `explain-config.json`，填入自己的 `apiUrl`、`apiKey`、`model`（例如阿里云 DashScope 等兼容 OpenAI 的接口）。
3. 也可在页面右上角「设置」中填写，会写入同一文件。

**注意**：`explain-config.json` 会包含 API Key，请勿提交到公开仓库或分享给他人。本压缩包内仅提供 `explain-config.example.json` 模板，不含真实密钥。

---

## 7. 安全提醒

- `explain-config.json` 含 API Key，勿提交到公开仓库，勿随压缩包传播。
- 本工具面向本机复盘，避免将含隐私/凭据的日志外传；共享前请脱敏（路径、用户名、密钥、业务数据等）。

---

按上述步骤操作后，在别的电脑上即可复现本辅助脚本（含可选 tool-logs 与解说 API）。更多接口与功能说明见解压后的 **log-viewer/README.md**。
